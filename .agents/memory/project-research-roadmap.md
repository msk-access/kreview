The post-v0.0.32 research campaign (2026-08) is documented on **issue #121** with every
number reproducible from `scripts/research_analyses/` (10 scripts, run against a local
outdir copy). Settled conclusions that should steer future sessions:

- **The modeling layer is saturated** (selector/meta-learner/stacking-granularity all
  ≤0.01 AUC — measured). Do not re-open those comparisons; gains live in the decision
  layer, features at low burden, and cohort design.
- **Operating points anchor on tumor-informed true negatives**, not the 68 healthy
  donors: `Possible ctDNA− AND has_paired_impact AND n_impact_confirmed==0` (4,414
  samples). Headline MRD number: sens@98spec-TN ≈ 0.48; 100% specificity is
  unattainable in the patient population.
- **LOD50 ≈ 4–5% VAF** (physics, not feature gap; >93% detection above 10% VAF).
  Fragmentomics score is a tumor-fraction meter (Spearman 0.78 vs VAF) — quantification
  = ordinal fraction bands.
- **Assay versions**: features fingerprint the assay perfectly (AUC 1.0) but the fix is
  per-assay threshold calibration, not per-assay models (generalization gap ~0.01).
- Open follow-ups tracked on #121: blinded chart review of variant-silent flags,
  CNVkit→ichorCNA hybrid TF (buffy coat = per-patient germline control),
  buffy-normalization fingerprint-collapse pilot, `True ctDNA−` labeler tier +
  dual-anchor report engineering. See [[feedback-terminal-failure-policy]] and
  `CONTINUITY.md` for the tactical state.

**Clinical review workbooks generated by these scripts contain sample identifiers and
exist only on the maintainer's machine — never committed, never attached anywhere.**
